# 网文小说平台用户行为数据分析
> 基于自研小说创作平台模拟业务数据，完成完整数据分析链路：数据模拟 → SQL指标统计 → Python清洗探索 → ECharts可视化看板 → 输出运营建议

## 📌 项目目标
搭建平台核心监控指标，分析用户阅读习惯、作品热度、转化漏斗，给运营提供优化方向

## 🛠 技术栈
MySQL SQL | Python(Pandas/Numpy/Matplotlib) | ECharts | Jupyter Notebook

## 📂 目录说明
- data/raw：原始模拟数据，包含用户、作品、阅读记录、收藏、评论表
- data/cleaned：清洗后可用数据集
- sql/：指标统计SQL脚本（DAU、热度排名、转化漏斗、时段分布，含窗口函数）
- notebook/：Python数据清洗+探索性分析代码
- report/：完整分析报告 + ECharts看板截图
- requirements.txt：依赖包

## ✅ 分析结论摘要
1. 用户阅读高峰集中在晚间20:00-22:00
2. 注册用户收藏转化率显著高于游客
3. 玄幻品类作品热度整体更高
## 💡 业务建议
1. 在晚间高峰时段定向推送新书
2. 游客阅读后引导注册，提升留存
3. 对低热度作品优化封面、简介
